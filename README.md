# VideoClub API — NestJS + TypeScript

This repository tracks an incremental, test-driven NestJS implementation of the VideoClub UML. The initial working foundation is proposed in a pull request.

The project is a **learning and portfolio project**, not a production rental system. Features will be built through GitHub Issues and reviewed pull requests.

See [open issues](https://github.com/samantonio91/videoclub-api-nestjs-ts/issues) for planned work.
